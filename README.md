# Autoenderezamiento pasivo de naves en Marte

Este proyecto estudia el potencial de los cuerpos monostáticos como sistema pasivo de autoenderezamiento para el aterrizaje de naves autónomas en Marte. Combina simulaciones bajo gravedad marciana con ensayos en arena de prototipos impresos en 3D, y compara una distribución de masa homogénea con otra concentrada en la base para evaluar las posibilidades y limitaciones de esta propuesta.
